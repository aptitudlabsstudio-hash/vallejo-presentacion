# Los heraldos negros

Exposición interactiva sobre César Vallejo. Desplázate para girar el libro y abrir sus páginas. También puedes usar las flechas, N para las notas y F para pantalla completa.

La escena proyecta geometría 3D local con WebGL o Canvas 2D. El modelo y su portada son una recreación visual. El índice, el glosario y las fuentes se consultan desde la presentación.
